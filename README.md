# 🚗 AutoCRM – Vehicle Service & Complaint Management System

## 📌 Overview

AutoCRM is a cloud-based Vehicle Service & Complaint Management System designed for automobile workshops and service centers.

The application allows administrators, technicians, and customers to manage vehicle complaints, work orders, inventory, suppliers, service history, and reports from a centralized dashboard.

The project is fully containerized using Docker and deployed on AWS EC2 with Nginx as a reverse proxy.
